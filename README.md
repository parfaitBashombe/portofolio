# 💼 My Personal Portfolio Website

This project is my **personal portfolio website**, created to showcase my skills, projects, and experience as a web developer and designer.  
It represents both my technical expertise and my approach to building modern, user-friendly web experiences.

---

## 🧠 Project Overview

The goal of this portfolio is to provide a clean, minimal, and professional platform where visitors can:

- Learn more about who I am and what I do
- Explore my featured projects
- View my technical skills and tools
- Contact me directly for opportunities or collaborations

The design follows a **modern, responsive, and minimal aesthetic**, emphasizing clarity and usability.

---

## ⚙️ Technologies Used

- **Next.js** – framework for fast and SEO-friendly web applications
- **React** – for building reusable and interactive UI components
- **TypeScript** – to ensure type safety and cleaner code
- **Tailwind CSS** – for responsive, utility-first styling
- **Framer Motion** – to create smooth, engaging animations

---

## 🎨 Design & Layout

The portfolio consists of several key sections:

1. **Home / Hero Section** – a brief introduction with call-to-action buttons
2. **About Me** – highlights my background, interests, and development journey
3. **Skills** – a categorized list of the technologies and tools I use
4. **Projects** – showcases selected projects with descriptions, tools used, and preview links
5. **Contact** – a simple contact form or email link for direct communication

The design is **fully responsive**, adapting seamlessly to mobile, tablet, and desktop screens.

---

## 🧩 Key Features

- 🧑‍💻 Well-structured and readable code
- 📱 Fully responsive layout
- 🌙 Optional dark/light mode toggle
- ✨ Smooth animations and transitions
- ⚡ Optimized performance with image optimization and lazy loading

---

## 🧱 Development Process

I started by designing the layout using **Figma**, ensuring the structure aligned with my personal branding.  
Then I implemented the layout using **Next.js** and **Tailwind CSS**, focusing on:

- Component reusability
- Accessibility
- Consistent color and typography
- Clean and maintainable code structure
